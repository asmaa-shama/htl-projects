# htl-projects

Eine ausgewählte Sammlung meiner Programmierprojekte aus der HTL. Dieses Repository dient als persönliches Portfolio, in dem ich eine exklusive Auswahl meiner Arbeiten im Software-Engineering und der Webentwicklung präsentiere.

---

## Projektübersicht

Hier finden Sie die ausgewählten Projekte im Detail. Klicken Sie auf den jeweiligen Link, um direkt zum Ordner und der spezifischen Dokumentation des Projekts zu gelangen:

### 1. VocabTrainer
* **Technologien:** Node.js, Express, Vanilla JavaScript (XHR), Bootstrap 5
* **Beschreibung:** Ein interaktiver Vokabeltrainer mit Flashcard-Flip-System, automatischem CSV-Import und persistentem Lernstatus (X/Hackerl Bewertung), der direkt im Server-Dateisystem gespeichert wird.
* **Ordner:** [/vocab-trainer](/vocab-trainer)

### 2. Wordle
* **Technologien:** Java, JavaFX
* **Beschreibung:** Die klassische Wortjagd als Desktop-Applikation umgesetzt mit JavaFX. Spieler müssen ein geheimes Wort mit fünf Buchstaben innerhalb von sechs Versuchen erraten, inklusive farblichem Feedback für richtige Buchstaben.
* **Ordner:** [/wordle](/wordle)

### 3. Season Activities Management App
* **Technologien:** Java, JavaFX (MVVM), JDBC (Oracle SQL)
* **Beschreibung:** Eine Desktop-Anwendung zur Verwaltung von Personen und deren saisonalen Aktivitäten. Setzt auf eine saubere MVVM-Architektur, bidirektionales JavaFX-Binding, ein Interface-basiertes Repository-Pattern und eine robuste JDBC-Datenbankanbindung.
* **Ordner:** [/season-activities](/season-activities)

### 4. 🔍 Item-Finder
* **Technologien:** JavaScript, Lit (Web Components)
* **Beschreibung:** Ein Frontend-Projekt basierend auf Lit-Webkomponenten, das ein schnelles Suchen, Filtern und Finden von bestimmten Gegenständen oder Datensätzen ermöglicht.
* **Ordner:** [/item-finder](/item-finder)
